# 安装包外观资源

这个目录**可以是空的**——里面每个文件都是可选的，缺了就用 Inno Setup 的默认外观，
编译照常通过（`MaxChemical.iss` 里全是 `FileExists` 探测后再用）。

放进来就自动生效，不用改任何脚本。

| 文件 | 管什么 | 格式与尺寸 |
|---|---|---|
| `setup.ico` | 安装包 exe 自己的图标（文件夹里看到的那个） | ICO，见下面尺寸说明 |
| `wizard.bmp` | 向导欢迎页 / 结束页左侧的竖长图 | **BMP**，164 × 314 |
| `wizard-small.bmp` | 其余页面右上角的小图 | **BMP**，55 × 55 |

## 三个图标各管各的，别搞混

| 你看到的图标 | 由谁决定 |
|---|---|
| 安装包 exe（`MaxChemical-Setup-1.0.0.exe`） | `assets\setup.ico`，没有就回落到主程序的 `app.ico` |
| 主程序 exe、桌面快捷方式、开始菜单、任务栏 | `MaxChemical.Shell\Resources\Icon\app.ico`（csproj 的 `<ApplicationIcon>`） |
| 控制面板「程序和功能」里的卸载项 | 主程序 exe，即上面那个 |

所以**只想统一换个 logo**，改 `app.ico` 一个文件就够了，安装包会跟着变。
只有想让安装包用一个跟主程序不同的图标时，才需要放 `setup.ico`。

## ICO 该做几档尺寸

一个 .ico 里可以塞多张位图，Windows 按场合挑。至少放这四档：

```
16×16    资源管理器详细列表、窗口标题栏
32×32    桌面图标、任务栏
48×48    资源管理器中等图标
256×256  大图标视图、Vista 以后的预览（这档必须是 PNG 压缩的）
```

只放一档 256 的话，缩到 16×16 会糊成一团——图标在小尺寸下要重新简化，
不是等比缩放能解决的。做图的同事应该懂这个，提需求时说清楚要多档就行。

在线转换工具很多，但**注意别把 256 那档做成未压缩位图**，
那样单个 ico 能到 300KB 以上，而且老系统上可能不识别。

## BMP 那两张的坑

- **必须是 BMP，Inno 不认 PNG。** 用 24 位色深，别存 32 位带 alpha 的——
  Inno 的向导图不做透明合成，透明区会变成黑块。
- 高 DPI 屏想清晰一点，可以按 `wizard@2x.bmp`（328 × 628）这样多放几档，
  Inno 会自己挑最合适的。不放也不影响，只是在 4K 屏上会有点糊。
- 大图的**下半部分会被向导文字压住**，重要内容（logo、名字）往上半部分放。
